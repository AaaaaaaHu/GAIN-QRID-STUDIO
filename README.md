# GIAN-QRID-STUDIO

基于 **Tauri 2 + Vue 3 + TypeScript + SCSS** 的桌面工具：按关键词批量生成**永不重复**的自定义 ID，同步生成对应二维码，本地留档，一键导出 ID 清单与二维码图片。

## 功能

| 模块 | 说明 |
| --- | --- |
| 关键词生成 | 每行 / 逗号 / 顿号分隔多个关键词 |
| 创建数量 | 两种模式：**总数量**（1–500，按关键词均分，如 3 词共 10 个 → 4/3/3）或 **每个关键词**（1–200）；带 10 / 50 / 100 / 200 快捷预设 |
| ID 自定义 | 前缀、城市编码（全国省 / 市 / 区县三级行政区划代码，悬停逐级展开，支持名称、代码、拼音、首字母搜索，可留空）、后缀、关键词段（    拼音首字母 / 全拼 / 原文 / 不使用）、日期、分隔符、序号位数、随机位、字符集、校验位 |
| 全局去重 | 生成前与「历史记录 + 永久去重库」比对，冲突则递增序号重试；删除记录也不会复用旧 ID |
| 二维码 | 内容模板 `{id} {keyword} {slug} {city} {date} {sequence}`，纠错等级、尺寸、边距、前景/背景色可调，改动实时重绘 |
| Logo 合成 | 上传图片（自动缩到 256px 内嵌），可选上 / 下 / 左 / 右 / 中心 五个安全位置，支持圆形裁切、白色衬垫、8%–24% 尺寸；三个定位角与右下对齐图案区自动禁用 |
| 扫描校验 | 五个位置 × 8%–24% 尺寸实测均可解码，导出包内 PNG 与预览完全一致 |
| 本地留档 | 桌面端写入 `%APPDATA%\com.gian.qrid.studio\`（`records.json` / `used-ids.json` / `config.json`），浏览器预览模式降级为 localStorage |
| 设置面板 | 右上角「设置」，四个标签页：外观（深浅主题 / 六套强调色 / 减少动效）、数据存储（目录切换 / 迁移 / 删除原数据）、软件版本（版本号与更新检查）、关于（功能亮点、隐私、技术栈与数据来源） |
| 导出 | CSV / JSON / TXT / 单张 PNG；「一键导出」打包 ZIP：ID 清单 + 每条记录一张二维码 PNG + 图文对照表 |

## 快速开始

```bash
pnpm install

pnpm dev          # 仅前端，浏览器预览（localStorage 模式，导出走浏览器下载）
pnpm tauri:dev    # 桌面应用开发模式
pnpm tauri:build  # 打包桌面安装包（安装包在 src-tauri/target/release/bundle/）
```

> 首次 `tauri build` 需要编译 Rust 依赖，耗时较长属正常。

## ID 规则示例

默认规则下，关键词「张三」生成：

```
ID-ZS-20261113-0001-KEZF-S
│  │  │        │    │    └ 校验位
│  │  │        │    └ 随机位（大写字母+数字，去除易混淆 I/O）
│  │  │        └ 序号（按历史递增，补零到 4 位）
│  │  └ 日期
│  └ 关键词拼音首字母
└ 固定前缀
```

设置了城市编码时，会在固定前缀之后多一段，例如 `ID-310000-ZS-20261113-0001-KEZF-S`；留空则保持上面的默认结构。

城市编码取自全国省 / 市 / 区县三级行政区划（3350 条，GB/T 2260 六位代码，数据源 `modood/Administrative-divisions-of-China`）。下拉默认只列 34 个省级行政区，鼠标悬停后向右追加该省的市，再悬停市追加区县，逐级收窄、不会一屏铺开几千条；北京 / 天津 / 上海 / 重庆的「市辖区」「县」等占位层级会自动跳过，选中后直接跳到区县。

也可以按名称、代码、全拼、首字母搜索，例如「杭州」「330100」「hangzhou」「hz」都能命中，搜索结果以平铺列表展示并标注所属省市；也可直接在输入框手填任意编码。

## 去重机制

1. **候选生成**：序号 + 随机位 + 校验位共同构成 ID；
2. **集合比对**：与历史上所有生成过的 ID（含已删除记录）比对，冲突即换序号 / 重摇随机位，最多重试 200 次；
3. **兜底**：极端情况追加碰撞标记 `X{n}`，保证 100% 唯一；
4. **持久化**：`used-ids.json` 独立保存，清空历史记录不影响去重库。

## 数据目录

默认位置：`%APPDATA%\com.gian.qrid.studio\`（Windows）。

在「设置」中可改为任意目录（例如 `D:\ID数据`）：
- 「浏览…」选目录，或直接粘贴路径；
- 勾选「把现有数据复制到新目录」会把三个 json 复制过去；
- 再勾选「迁移成功后删除原目录中的三个数据文件」可在二次确认后清理旧数据，只删这三个文件，不动目录内其他内容；
- 删除仅在复制确实成功后执行，避免中途失败丢数据；
- 修改后立即生效，无需重启；自定义路径记在本地，下次启动自动沿用；
- 目录被移动 / 磁盘未连接时，设置页会显示红色告警，数据不会被覆盖。

```
GIAN-ID与二维码_20261113_153000_120条.zip
├── GIAN-ID清单.csv          # 带 BOM，Excel 直接打开不乱码

├── GIAN-ID纯列表.txt        # 每行一个 ID
```
